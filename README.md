# Implantación de Sistemas Operativos — Administración Linux y Windows

Proyecto final del ciclo de ASIR: administración y securización de sistemas 
Linux y Windows 10, incluyendo gestión de usuarios, auditoría, backups, 
almacenamiento y recursos compartidos en red.

📄 [Ver documento completo con capturas](docs/implantacion-sistemas-operativos.docx)

## 🐧 Parte 1: Linux

### Gestión de usuarios y procesos
- Creación de usuarios y grupos (`useradd`, `groupadd`)
- Gestión de permisos con `sudo` y `chmod`
- Control de procesos (`ps aux`, `kill`, `nice`, `renice`)

### Auditoría, backups y monitorización
- Auditoría de accesos con `auditd`
- Backups automatizados con `cron`
- Sincronización de directorios con `rsync`
- Monitorización de recursos con `top`

### Ficheros, volúmenes y recursos en red
- Particionado con `fdisk` y montaje de volúmenes
- Gestión de almacenamiento con LVM (Logical Volume Manager)
- Compartición de recursos con Samba y control de acceso por grupos

## 🪟 Parte 2: Windows 10

### Gestión avanzada de usuarios y seguridad
- Creación de usuarios con permisos diferenciados
- Directivas de grupo local (GPO) mediante registro
- Carpetas compartidas con acceso restringido
- Scripts `.bat` de inicio de sesión

### Monitorización y gestión de recursos
- Monitor de rendimiento (CPU/RAM)
- Tareas programadas personalizadas

## 🛠️ Herramientas y tecnologías
`Linux` `Bash` `auditd` `cron` `rsync` `LVM` `Samba` `Windows Server tools` `GPO` `Batch scripting`
